# The end state

What this repository is aiming at, written down so every session — human or agent,
warm or cold — is walking toward the same place. The roadmap records how we got here
and what is next; this document records where "next" terminates. The aim, stated
once: **programming as a correct-by-construction activity.** Every gap between
"the change I intended" and "the change that is true" closed by the medium, not by
memory, discipline, or review-time vigilance.

The method's one move — derive the fact, ratify the decision — does not change at
the end. What changes is how much of the world it has eaten.

## Nothing is learned twice

Sessions here start cold. No agent remembers the last agent's confusions; the tree
is the only inheritance. So the first asymptote: **structure is the only memory.**
Every reading a session takes, every confusion it burns time on, becomes a verb, a
lock, or a refusal before the session ends — and then no future session can even
encounter the problem. The toolchain pin is the miniature: the knowledge "you must
run `rustup default`" died the day it became a file rustup obeys. At the end state
there is no documentation *for* agents, because the distinction between
documentation and tool has dissolved. A cold start inherits every prior session's
skill without inheriting a paragraph of advice.

## The text file goes archaic

The interface to the code is the CLI's verbs; the file is a render. At the end
state that is literally true: the journal is the medium of change, every question
an agent can hold is a perception verb, every change an agent can intend is a
judged transaction at the grain of the intent — item, method, expression. Nobody
patches text, so nobody can patch text wrongly. Git remains as one more derived
artifact of the journal, the way `ci.yml` is a derived artifact of the gate
registry today. "Opening a file to read its interior" sounds, from the end state,
the way "poking bytes into memory" sounds now.

## No unkeyed green

One invariant, enforced at every altitude at once: **a verdict cannot exist
without a key naming exactly what it judged.** No remembered green, no selector
that matches nothing and passes, no claim whose support is a hope. The same
failure class has now been caught at five altitudes (gate verdicts, mutation
locks, the perimeter, semver, the flip selector); the end state stops catching
instances and installs the rule. Its strongest form is the whole aim in one
sentence: the refusal migrates from run time to construction time, until an
unjudgeable state is an unrepresentable one — being wrong is not detected but
*unsayable*.

## Evidence becomes construction

Today the batteries sample and the grids are bounded, so a green law is evidence.
That is a property of the current instrument, not of the method — and it is the
next gap to close, not a permanent modesty. Outside work has now demonstrated
machine-generated code shipping with machine-checked end-to-end proofs, authored
in minutes; the route from "sampled refutation" to "discharged theorem" is open.
This repository is unusually well-positioned to walk it: the shape catalog already
states every law as a typed, slotted equation — a proof obligation in everything
but name — and the declared/derived split already separates what must be proved
from what must be decided. The end state: a declared law is *discharged*, not
probed; the battery survives as the counterexample-hunter for conjectures not yet
proven and as the fast judge during authoring; the mutation sweeps retire
degree-of-freedom by degree-of-freedom as the proofs pin each one. The HoTT frame
names where this points: the spec is the type, implementations are its
inhabitants, and an equivalence between two implementations is a path — "derive
the spec by running the thing" inverted, at last, into "inhabit the spec by
construction."

## The roadmap derives itself

The strongest signal this repository produces today is convergence — independent
cold sessions hitting the same friction — and it is tallied by hand in prose. At
the end state the journal measures it: change locality, friction recurrence,
refusal frequency, per-demand delta size, and the environment names its own next
brick with the evidence attached. The standing question — "what is secretly a
derivation plus a signature?" — pointed at its own backlog, permanently.

## What remains

One thing, and it is not a gap: the loss function. Which demands ought to exist,
which freedoms are worth keeping, what the thing is *for* — that is judgment, and
its signature stays human. Everything between a human's "this ought to be true"
and the machine's "it is, constructively" belongs to the medium. The end state is
reached when that sentence describes the whole distance.
